## Fonts

In **Theme settings > Typography**:

{% include figure.html src="theme-settings/panel-typography" alt="The Typography group in theme settings: heading font, heading letter spacing and size scale, body font and line height" caption="Theme settings > Typography." mobile=true %}

| Setting | Description |
| --- | --- |
| Heading font | Used for headings. Choose any font from the Shopify font library. |
| Heading letter spacing | Adds or removes space between heading letters. |
| Heading size scale | Scales every heading size up or down in proportion. |
| Body font | Used for body text, buttons, navigation and forms. |
| Body line height | Space between lines of body text. |

Fonts from the Shopify font library are served by Shopify and load quickly. Some fonts in the library are system fonts that don't download at all.

<div class="callout"><p>Every preset uses a distinctive heading font and a readable body font. When you change them, check headings in other languages too: not every font includes every character.</p></div>

## Layout

In **Theme settings > Layout**:

| Setting | Description |
| --- | --- |
| Maximum page width | **Narrow (90rem)** or **Wide (110rem)**. Content stops growing beyond this width on large screens. |
| Minimum page margin | The space between content and the edge of the screen. |

## Buttons

In **Theme settings > Buttons**: **Border radius**, **Vertical padding**, **Horizontal padding**, **Font size** (**Small**, **Regular** or **Medium**), **Uppercase text** and **Letter spacing**. Button colors come from the [color scheme]({{ '/colors/' | relative_url }}).

## Product cards

In **Theme settings > Product cards**: **Image ratio**, **Text alignment** and **Align rows across cards**. See [Theme settings]({{ '/theme-settings/#product-cards' | relative_url }}).
