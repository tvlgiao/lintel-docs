## Included languages

| Language | Storefront text |
| --- | --- |
| English | Included (default) |
| French | Included |
| Spanish | Included |

Setting labels in the theme editor are in English.

Storefront text is everything the theme writes for shoppers: button labels, cart messages, form labels, accessibility labels and so on. Text you type into section settings is your own content and is translated separately.

## Change the theme's storefront text

To reword any built-in text, such as "Add to cart":

1. Go to **Online Store > Themes**.
2. On Lintel, select **⋯ > Edit default theme content**.
3. Search for the text, change it and select **Save**.

This keeps your change when you update the theme. You don't need to edit code.

## Sell in more languages

1. Add the language in **Settings > Languages** and publish it.
2. Install the free **Translate & Adapt** app (or another translation app) to translate your products, collections, pages and section content.
3. Turn on **Show language selector** in the Header or Footer section so shoppers can switch languages. The selector appears only when your store has more than one published language.

For languages other than English, French and Spanish, the theme's storefront text can be translated in the translation app or in **Edit default theme content**.

## Right-to-left languages

When the storefront language is a right-to-left language such as Arabic, Hebrew, Persian or Urdu, Lintel mirrors its layout: navigation, drawers, galleries and text alignment flip direction.

## Currencies and countries

Shopify Markets handles currencies and countries. Turn on **Show country/region selector** in the Header or Footer section to let shoppers choose; it appears only when your store sells in more than one country.
