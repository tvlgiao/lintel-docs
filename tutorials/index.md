<p><strong>Before you change anything, duplicate your theme.</strong> In <strong>Online Store &gt; Themes</strong>, select <strong>⋯ &gt; Duplicate</strong> on Lintel and make your changes on the copy. Publish the copy only when you're happy with it. If something goes wrong, your original theme is untouched.</p>

Custom code is your own work. Our [support policy]({{ '/support/' | relative_url }}) covers the theme as we ship it, so we can't write, fix or maintain custom code for you. For larger changes, we recommend hiring a [Shopify Partner](https://www.shopify.com/partners/directory).

| Tutorial | Is it supported? |
| --- | --- |
| [Add custom CSS in the theme editor]({{ '/tutorials/custom-css/' | relative_url }}) | The Custom CSS feature is supported. The CSS you write is not. |
| [Add a Custom Liquid section or block]({{ '/tutorials/custom-liquid/' | relative_url }}) | The Custom Liquid section and blocks are supported. The code you write is not. |
| [Edit theme code files]({{ '/tutorials/edit-theme-code/' | relative_url }}) | Not supported. Code edits also stop automatic theme updates from carrying your change over. |

## Try settings first

Many changes need no code:

- Reword built-in text in **Online Store > Themes > ⋯ > Edit default theme content**. See [Translations]({{ '/translations/' | relative_url }}).
- Change colors per section with color schemes. See [Color schemes]({{ '/colors/' | relative_url }}).
- Use apps that provide **app blocks**; most Lintel sections accept them.
